## 🔧 Customization Tips

### Change Primary Color
```css
:root {
    --primary: #YOUR_COLOR;
    --primary-dark: darker-shade;
    --primary-light: lighter-shade;
}
```

### Adjust Spacing
```css
.section { padding: 2rem 0; /* Change this */ }
.container { max-width: 1200px; /* Or this */ }
```

### Modify Fonts
```css
body { font-family: 'Your Font', sans-serif; }
```
