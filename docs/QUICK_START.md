## 🎨 Design System Explained

### Color Meanings
- **Green (#22c55e)** = Success, primary action
- **Red (#ef4444)** = Error, warning
- **Blue (#0ea5e9)** = Information, secondary action
- **Yellow (#eab308)** = Pending, caution
- **Gray** = Disabled, muted, secondary

### Button Types
- **Green Button** = Main action, do this
- **Gray Button** = Secondary action, optional
- **White Button** = Light action, less important
- **Outline Button** = Alternative choice

### Icons Meaning
- **Leaf** = FarmLink/Home
- **Basket** = Shopping/Products
- **Box** = Orders/Packages
- **Chat** = Messages/Offers
- **Person** = Profile/Account
- **Gear** = Settings
- **Bell** = Notifications
- **Search** = Find things
